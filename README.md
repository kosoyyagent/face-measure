# Антропометрия лица по фото

Веб-приложение: пользователь загружает фото анфаса и профиля, ИИ (MediaPipe FaceLandmarker, 478 точек) автоматически расставляет ключевые точки, программа рисует их на фото и считает параметры.

## Что измеряет
- Длина и ширина лица, ширина скул/челюсти/лба
- Межзрачковое расстояние (используется как масштаб для миллиметров)
- Ширина и высота глаз, длина/ширина носа, ширина рта
- Полнота верхней и нижней губы
- Пропорции лица и углы челюсти

## Функции
- Две вкладки: анфас и профиль
- Любую точку можно перетащить мышью — все измерения пересчитываются мгновенно
- Экспорт фото с точками (PNG) и таблицы измерений (CSV)
- Работает локально в браузере: один файл `index.html`, сеть нужна только для загрузки модели MediaPipe с CDN (при желании модель скачивается и кладётся рядом — полный офлайн)

## Запуск
Открыть `index.html` в браузере (или разместить на любом статическом хостинге).

## Масштаб
По умолчанию миллиметры выводятся по калибровке через межзрачковое расстояние (63 мм). Для точных замеров пользователь вводит своё значение или калибрует по объекту известного размера в кадре — добавляется одним полем.
